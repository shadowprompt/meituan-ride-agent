# 主界面简化：截图优先，不冒充端到端完成

## 普通使用路径

1. 在本地网页选择原始截图。
2. 阅读页面顶部能力限制及本次上传范围，明确勾选授权。
3. 点击“开始识别”。默认真实视觉 API、道路走廊目标，不再要求先切目标、填道路名或上传技术文件。模型服务须由管理员预先配置；配置缺失时不上传、不偷偷切到 Demo。
4. 查看“结果 / 具体缺口”与当前产物。缺少本地地图时，用自然语言说明仍缺自动地图能力，不让普通用户照抄 JSON。只读状态轮询不会重新执行任务。

## 能力边界

这是 UI 简化，不是“原图 → 自主定位 → 自动地图 → 经纬度”的端到端完成。后台尚无根据截图自动确定地理范围并获取地图的链路。模型可能读出地名、道路信息，但没有获授权地图证据时不能据此编造坐标。本地地图存在也不代表数据有效、道路已找到或结果已验证。

不注入真实道路假设，不生成控制点，不自动下载地图；创建请求只发送截图、模式、目标与本次上传授权，不读取高级表单内可能残留的道路名、地图或下载选择。API 配置与模型失败仍沿用已有安全报错，不重试上传。

## 高级操作仍可用

- “高级选项：运行模式与手动目标”：切换明确标为固定演示的离线 Demo，或像素、严格配准、近似定位等已有目标。
- “恢复已有任务”：粘贴任务编号、刷新状态，只读取，不自动恢复执行；原始状态 JSON、问题证据及模型候选决定在此查看。
- 候选像素面板默认收起，有候选时自动展开；原有可视选择、本地应用与单独授权的模型复核保留。
- 逐孔纠错、颜色/裁剪、控制点 JSON、本地 OSM、地图独立下载授权、道路名与有据道路假设均保留在默认折叠高级工具内。
- 高级“继续处理”仍使用原有授权及校验，不绕过配准门槛；道路走廊仍与严格配准及地图下载隔离。走廊任务已有本地地图后可重新授权模型读图，不必强制手填道路假设。

所有输出仍为未验证候选，非原始 GPS、不可导航。旧任务不会在打开页面或点击刷新时自动重放。

## 回归验证

`PYTHONPATH=src:test python3 -m unittest discover -s test -v`

`test_web_simple_ui.py` 验证默认折叠结构、默认目标与模式、授权不预选、缺地图自然语言提示、创建不带高级残留证据、恢复只 GET，以及状态仅公开当前本地地图存在事实。模拟 DOM/CLI 和合成空地图仅为测试，不是生产道路证据；测试不调用外部模型或地图。
